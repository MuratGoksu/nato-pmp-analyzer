## 💡 Tips for Demo Questions

### Do's ✅
- **Start simple, build to complex**
- **Use your actual project names** when customizing
- **Let each answer finish** before next question
- **Expand source citations** to show evidence
- **Explain what the AI is doing** while it thinks
- **Highlight accurate insights** in the response
- **Show enthusiasm** when AI gives great answers

### Don'ts ❌
- **Don't ask questions you haven't tested**
- **Don't rush through responses**
- **Don't skip showing sources**
- **Don't ask vague questions** ("Tell me about projects")
- **Don't interrupt the AI** while it's responding
- **Don't apologize** if response is slower

## 🧪 Pre-Demo Testing

**Before your demo, test ALL questions with your actual documents:**

### Testing Checklist
- [ ] Run each question category
- [ ] Verify responses are accurate
- [ ] Check that sources are cited
- [ ] Ensure response time is <10 seconds
- [ ] Note any questions that don't work well
- [ ] Prepare backup questions
- [ ] Practice your explanations
- [ ] Time the full question flow

### Document Your Results
For each question:
- ✅ Works perfectly
- ⚠️ Works but needs context
- ❌ Doesn't work well (skip in demo)
