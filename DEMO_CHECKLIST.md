## 🚨 **Emergency Procedures**

### If Computer Crashes
1. Have backup laptop ready
2. Use backup USB to restore
3. Worst case: show demo video
4. Apologize briefly, move forward

### If Internet Fails
1. Use mobile hotspot as backup
2. Some features work offline (after initial setup)
3. Fall back to presentation slides
4. Offer to reschedule demo

### If OpenAI API Fails
1. Explain RAG depends on API
2. Show basic pattern-matching chatbot
3. Focus on other features (upload, dashboard, networks)
4. Offer follow-up when API is back

### If Questions Stump You
1. "Great question! Let me note that for follow-up"
2. "I don't want to guess - let me research and get back to you"
3. "That's beyond current scope but we can explore it"
4. Never make up answers!
